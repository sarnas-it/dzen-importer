Импорт публикаций из канала Дзен в WordPress: полный текст, картинки, миниатюра и SEO-поля.

== Description ==

Плагин раз в N минут проверяет канал Дзена и переносит новые публикации на сайт:

* полный текст статьи с подзаголовками, списками и картинками;
* картинки скачиваются в медиатеку, обложка становится миниатюрой;
* оригинальная дата публикации и человеческий слаг (транслитерация);
* SEO-поля для Yoast, Rank Math, AIOSEO, SEOPress, Slim SEO или свои мета-теги;
* ссылка на источник в конце записи — включается и отключается.

При первом запуске плагин фиксирует текущие публикации канала и импортирует только новые.
Архив можно догрузить вручную.

== Installation ==

1. Загрузите папку `dzen-importer` в `/wp-content/plugins/`.
2. Активируйте плагин через меню «Плагины».
3. Откройте «Настройки → Импорт из Дзена», укажите канал и сохраните настройки.
4. Нажмите «Синхронизировать сейчас», чтобы зафиксировать текущее состояние канала.

== Frequently Asked Questions ==

= Почему нет обычного RSS? =

Дзен не отдаёт RSS для каналов. Плагин использует публичный JSON-фид и SSR-страницы статей.

= Будут ли дубли при повторном запуске? =

Нет. Каждая публикация запоминается по ID и повторно не импортируется.

= Переносятся ли видео и шортсы? =

Нет, только текстовые публикации.
